    For grown-ups

    What ColouringAI does

    Your child builds an idea by tapping pictures (who, what they're doing, where). Pip reads everything aloud, so no reading or typing is needed. Claude then draws a simple line-art colouring page, which your child can colour on screen or save as a PDF to print.

    Kept G-rated

    • Children choose only from friendly picture tiles, so there is nothing unsuitable to ask for.
    • Claude is told to draw only gentle, cheerful, child-friendly pictures, and the picture's title is checked by a word filter before it is shown.
    • Only simple outline shapes are accepted from the AI, so no text, links or outside images can appear.

    Uses your Claude account

    Each drawing is made by Claude Sonnet and uses a little of the Claude usage of whoever is viewing the page. The first time, Claude asks you to allow this. If you don't allow it, Pip uses a few built-in pictures instead.

    About voice and printing

    Pages on claude.ai can't use the microphone or open the print window. So this version uses picture tiles instead of voice, and gives you a PDF to print. The full voice version (speak your idea, prints automatically) runs in Chrome, Edge or Safari from the project files. See the README.

    Saved pictures are kept only in this browser.
